계정 관리

계정·데이터 삭제 안내

잘씀은 앱 안에서 계정을 삭제할 수 있습니다. 앱에 접근할 수 없어도 이메일로 삭제를 요청할 수 있습니다.

앱에서 직접 삭제

  1. 잘씀에서 삭제하려는 계정으로 로그인합니다.
  2. 설정 → 계정 삭제를 선택합니다.
  3. 이메일 계정은 비밀번호로, 소셜 계정은 가입할 때 사용한 계정으로 본인을 다시 확인합니다.
  4. 소셜 계정은 확인 후 2분 안에 ‘영구 삭제’를 입력하고 계정과 내 가계부 영구 삭제를 누릅니다.
먼저 필요한 자료를 내보내세요.
계정 삭제는 되돌릴 수 없습니다. 본인이 만든 공동 장부는 다른 구성원에게도 사라집니다.

삭제되는 자료

  • 잘씀 로그인 계정과 계정에 연결된 식별 정보
  • 본인이 소유한 개인·공동·사업 장부와 그 안의 거래·예산·금융 기록
  • 본인이 올린 첨부 파일과 본인 소유 장부의 첨부 파일
  • 장부 구성원 자격과 앱이 관리하는 이 기기의 계정별 미저장 초안

다른 사람의 자료와 구매 내역

다른 사람이 소유한 공동 장부에 작성한 거래는 작성자 계정과의 연결을 해제한 상태로 남습니다. 거래 메모에 직접 쓴 개인정보는 자동으로 구분할 수 없으므로, 필요한 경우 먼저 수정하거나 운영팀에 삭제를 요청하세요. 이미 내보내거나 다른 구성원이 보관한 파일은 앱에서 회수할 수 없습니다.

App Store·Google Play가 관리하는 구매 영수증·결제 내역은 잘씀 계정 삭제와 별개입니다. 계정 삭제가 구매 취소나 환불을 자동으로 신청하지 않습니다.

앱을 사용할 수 없을 때

계정 삭제 요청 이메일 보내기

사용한 로그인 방법과 삭제를 원하는 범위(계정 전체 또는 특정 개인정보)를 알려주세요. 다른 사람의 자료가 삭제되지 않도록 본인 확인 방법을 별도로 안내합니다. 이메일 주소나 이름만으로 계정을 합치거나 삭제하지 않습니다. 비밀번호와 인증번호는 요청하지 않습니다.

요청은 본인 확인 후 지체 없이 처리하며, 법령상 보관 의무나 공동 자료 등 즉시 삭제할 수 없는 범위가 있으면 이유와 처리 방법을 안내합니다. 개인정보처리방침
